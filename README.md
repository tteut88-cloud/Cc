# 우리 캘린더 💗

상대와 나, 둘만 공유하는 캘린더 (설치형 웹앱 / PWA). 빌드 과정이 없으며 정적 파일만으로 동작합니다.

## 실행
```bash
python3 -m http.server 8000
# 내 화면:   http://localhost:8000/
# 상대 화면: http://localhost:8000/?as=b   (같은 기기, 다른 탭 → 실시간 공유)
```
휴대폰에서는 GitHub Pages 등에 올린 뒤 "홈 화면에 추가"하면 앱 아이콘(고양이 폴더)으로 설치됩니다.

## 화면
| 화면 | 동작 |
|---|---|
| ① LIST | 오늘 날짜·요일, 할 일 체크(줄 긋기), 💗함께 할 일, GPS 날씨(비/눈이면 LIST 옆 동그라미가 파란색). **LIST** 누르면 ② |
| ② 월 달력 | 😊 탭: 일정↔사진 보기 전환 · 😊 꾹: 표정 골라 상대에게 알림 · 월 표기: 월 이동 · 🔍: 검색 · 칸 탭: ③ · 칸 꾹 → 다른 칸 탭: 여러 날 일정 · 좌우 스와이프로 월 이동 |
| 표시 | 파란 스티커+얇은 선 = 비 오는 날 · 숫자 밑 굵은 선 = 메모 · 이어진 막대 = 여러 날 일정 · 우측 하단 검은 삼각형 = 데드라인 · 빨간 선 = 레드라인 기간 |
| ③ 하루 | 위: 날짜 스트립(가로 스크롤) · 숫자 꾹: "이 기간까지 레드라인을 설정하겠습니까?" · 당일 숫자 꾹: ⑨ · 아래: 오전 12시~오후 11시, 빈 칸 탭으로 일정 등록, 일정 사각형 탭하면 메모 표시 |
| ⑨ 함께 보는 일정 | 내 일정 / 상대 일정 반반 |
| ④ 메모 □ | 사진+메모, 날짜 지정, 💗 상대에게 보내기 → 상대 알림 |
| ⑤ ＋ | 상대 캘린더 ↔ 내 캘린더 전환 |
| ⑥ ≡ 기록 | 같이 해야 할 일, 상대가 보낸 메모, 알림 |
| ⑦ ○ 설정 | 글씨체, 테마(화이트/핑크/크림/다크), 컬러 설정, 글자 크기, 이름, 알림 허용 |
| ⑧ 컬러 설정 | 일정/계획/메모/공유 각자 설정 — 공유 색은 상대 캘린더에도 그대로 표시 |

### 표정 규칙
상대가 표정을 바꾼 뒤 **처음 앱을 열 때 한 번만** 그 표정이 보이고, 이후엔 다시 바꿀 때까지 스마일로 보입니다. 바꾼 지 1시간이 지나면 스마일로 초기화됩니다.

## 데이터 / 공유
현재는 기기 안(localStorage)에 두 사람의 데이터를 함께 저장하고, 같은 기기의 탭끼리 실시간으로 동기화합니다.
서로 다른 휴대폰끼리 공유하려면 `app.js`의 `load()/save()`와 `storage` 이벤트 부분을 Firebase·Supabase 같은 실시간 DB로 바꾸면 됩니다.

날씨: [Open-Meteo](https://open-meteo.com) (API 키 불필요), 위치 권한이 없으면 서울 기준.
