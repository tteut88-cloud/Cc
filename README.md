# nneow

상대와 나, 둘만 공유하는 캘린더 (설치형 웹앱 / PWA). 빌드 과정이 없으며 정적 파일만으로 동작합니다.

## 실행
```bash
python3 -m http.server 8000
# 내 화면:   http://localhost:8000/
# 상대 화면: http://localhost:8000/?as=b   (같은 기기, 다른 탭 → 실시간 공유)
```
휴대폰에서는 GitHub Pages 등에 올린 뒤 "홈 화면에 추가"하면 앱 아이콘(고양이 폴더)으로 설치됩니다.

## 화면
| 화면 | 동작 |
|---|---|
| ① LIST | 오늘 날짜·날씨, **오늘 일정**(내 일정 + 상대가 공유한 일정)이 체크리스트로 표시. 체크하면 줄 긋기. 할 일 추가는 달력에서 일정으로 |
| ② 월 달력 | 😊 탭: 일정↔사진 · 😊 꾹: 표정 + 스티커(하트·별·네잎클로버를 상대 캘린더의 빈 날에 붙이기) · 칸 꾹 → 다른 칸 탭: 여러 날 일정 |
| 표시 | 비 올 확률 70% 이상 = 연한 파란 네모 · 메모 = 메모 색 바 · 이어진 막대 = 여러 날 일정 · 우측 하단 검은 삼각형 = 데드라인 |
| 아래 탭 | □ 메모 · ＋ 상대 캘린더 전환(꾹: ① LIST) · \|\|\| 공유 갤러리(꾹: ⑨ + 상대 오늘 진행률) · ○ 설정 |
| ③ 하루 | 날짜 줄(선택한 날은 연한 붉은 원) · 숫자 꾹: 레드라인 / 당일 꾹: ⑨ · 빈 칸 탭: 일정 등록 · 상대 일정 꾹: 메모 남기기(접근 허용 시, ● 표시) |
| ⑨ 함께 보는 일정 | 상대의 오늘 진행률(상대 LIST 기준) + 내 일정 / 상대 일정 반반 |
| ④ 메모 | **모아보기**: 목록/바둑판, ‘나만 보는 메모’ 체크 · **나누기**: 메모장 디자인으로 주고받기, 사진 첨부, 왼쪽으로 밀어 답장, 내 메모 꾹: 수정/삭제, **콕 찌르기** |
| 갤러리 | 둘이 함께 쓰는 사진첩. 사진 누르면 정보·메모. 안드로이드는 휴대폰 갤러리에서 ‘공유 → nneow’로 바로 보내기 |
| ⑦ 설정 | 상대방 접근 허용, 상대 휴대폰과 연결, 다른 캘린더와 동기화, 글씨체, 테마, 컬러, 글자 크기, 이름, 알림 |
| ⑧ 컬러 설정 | 일정/계획/메모/공유 각자 설정 — 공유 색은 상대 캘린더에도 그대로 표시 |

### 표정 규칙
상대가 표정을 바꾼 뒤 **처음 앱을 열 때 한 번만** 그 표정이 보이고, 이후엔 다시 바꿀 때까지 스마일로 보입니다. 바꾼 지 1시간이 지나면 스마일로 초기화됩니다.

## 상대 휴대폰과 연결 (Firebase)
설정 → **상대 휴대폰과 연결** → 로그인 → 한 사람이 **초대 코드 만들기**, 상대가 **코드 입력**.
일정 · 메모 · 표정 · 대화 · 사진이 두 휴대폰 사이에 실시간으로 동기화됩니다. 연결 전에는 기기 안에만 저장돼요.

Firebase 콘솔에서 한 번만 해둘 것:
1. **Firestore Database** → 규칙 탭 → `firestore.rules` 내용을 붙여넣고 **게시**
2. **Authentication** → 로그인 방법 → **Google** 사용 설정 (선택: **익명**도 사용 설정하면 ‘로그인 없이 시작’ 가능)
3. 앱을 올린 주소를 Authentication → 설정 → **승인된 도메인**에 추가 (Firebase Hosting 주소는 자동 등록)

배포 (둘 중 하나):
- Firebase Hosting: `npm i -g firebase-tools && firebase login && firebase deploy` → `https://nneow-5a0ac.web.app` (보안 규칙도 같이 배포됨)
- Netlify Drop: 폴더를 https://app.netlify.com/drop 에 끌어다 놓기 → 받은 주소를 승인된 도메인에 추가

로컬 테스트: `firebase emulators:start --only auth,firestore` 실행 후 `http://localhost:8000/?emu=1`

날씨: [Open-Meteo](https://open-meteo.com) (API 키 불필요), 위치 권한이 없으면 서울 기준.
